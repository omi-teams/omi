TASK-123 · UI specification for PO approval

Scope and screens

Preserve the existing omi board brand, Vietnamese UI copy, system fonts, SVG assets and light/dark palettes. No dependency, CDN, network request or new application screen. Projects, project dashboard and task detail share the changed header. The mockup data is illustrative; task details are abbreviated to show unchanged layout.

Review projects.html, project.html, task.html and phone.html; expand the state gallery on each. Phone uses a 375px viewport when opened on desktop; all screens remain responsive at 320px and 200% zoom. Desktop max width 1200px; below 768px use 16px gutters and a single kanban column. Task sidebar collapses below 960px. Preserve existing mobile kanban ordering and collapsed empty columns in the application.

Header and copy

Remove the auto-refresh checkbox, its label, countdown, saved preference and all corresponding CSS. Keep brand, source/revision, breadcrumb, last successful data-update time and the “Làm mới” button. Mobile retains the visible button label and wraps timestamp onto its own line. Button accessible name: “Làm mới”. Timestamp remains “Cập nhật lần cuối HH:mm:ss”. No polling indicator, countdown or new switch.

Behavior and all states

Check version every 3 seconds while visible, silently. A matching version leaves DOM, timestamp, scroll, expanded reports and keyboard focus untouched. On a changed version, reload only the current view, retaining old content while loading. Update timestamp and source only after successful full-data load. Pause polling while hidden; check once on visibility return and resume cadence. Manual refresh and “Thử lại” fetch current-view data immediately. Do not show a skeleton for background checks or background data reloads.

Initial load: route title plus static skeleton and “Đang tải…”, view aria-busy. During initial/manual/retry data request, disable only its request button with native disabled and visible “Đang tải…”; restore original label on completion. Background checks leave manual refresh enabled. Preserve focused control identity through background updates; if removed, move focus to the closest surviving context. Never focus the heading on background refresh. Keep report disclosure state and scroll.

Failure: keep old content and timestamp, show existing inline role=alert with “Không tải được dữ liệu (quá thời gian chờ).” or the existing HTTP error code, and “Thử lại”. No toast, modal or raw exception detail. Announce one error per failure episode, not every poll. First-load failure keeps route title and error, no fake data. Continue visible polling and clear warning only after successful data reload. Cached/stale source uses existing “Dữ liệu cũ - không kết nối được GitHub (lúc HH:mm:ss)”. Empty states use existing copy shown in the gallery. Fresh data recovery is announced once via the existing polite status region.

Typography, tokens and interaction

Use repository system-ui, -apple-system, Segoe UI, sans-serif; monospace ui-monospace, Cascadia Mono, Consolas. Body 15px/1.5, h1 26px (24px mobile), h2 15px/650, supporting copy 13px, buttons 14px; tabular numerals. Keep all existing tokens. Light: bg #f6f6f4, foreground #1f2421, surface #ffffff, muted #5f6661, accent #0f6e6e, hover #0a5252; dark: bg #191e1c, foreground #e3e9e5, surface #232a26, muted #a9b6ad, accent #78c9c2. Use muted token for interactive button border to reach 3:1; existing pale line tokens are decorative only.

Spacing: 6/8/12/16/20/24/28/48px; header 10px 24px, content 28px 24px 48px; panels 20px (16px mobile), grid gap 12–20px. Radii: buttons 6px, cards 8px, panels 10px. Focus outline 2px accent with 3px offset. Refresh/retry targets 44px tall. Hover uses accent border/text; press scales .98; 220ms transform/opacity cubic-bezier(.32,.72,0,1), no background loading animation, no motion under prefers-reduced-motion.

Accessibility requirements

WCAG 2.2 AA: text 4.5:1, controls/focus 3:1, semantic buttons and landmarks, one h1, heading order, current breadcrumb aria-current, visible skip link on focus, Vietnamese lang and unique document titles. Tab follows reading order; Enter/Space activate buttons and disclosures. Do not steal focus or repeatedly announce unchanged polls. Sticky header must not obscure focused elements. All content reflows at 320px; zoom is allowed. Status is textual, never colour-only. Review by source only; browser focus, zoom and screen-reader behavior remain engineering/QA verification.
